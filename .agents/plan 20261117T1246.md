# Plan: Header Diff View for CUE Files (.cue vs .cue.bak)

## 1. Overview & Objective
Implement a `diff` view in CueComplete that compares the current `.cue` file header metadata against its backup version (`.cue.bak`).
Per requirements:
- Compare only the header metadata fields currently shown in the `Source cue details` pane.
- Ignore all audio track information (`TRACK`, `INDEX`, track titles, etc.).
- Clearly indicate what fields are added, modified, removed, or unchanged.

---

## 2. Requirements & Field Scope

### A. Fields to Compare
Only the fields formatted in `Source cue details` (`FormatCueData`):
1. **Artist**: `data.Artist`
2. **Album**: `data.Album`
3. **Genre**: `data.Genre`
4. **Date**: `data.Date`
5. **Label**: `data.Label`
6. **Cat No**: `data.CatalogNumber`
7. **Country**: `data.Country`
8. **Barcode**: `data.Barcode`
9. **Rel Date**: `data.ReleaseDate`
10. **Discs**: formatted disc info (`DiscNumber` & `Discs`, e.g. `"1 of 2"` or `"1"`)
11. **Comment**: `data.Comment` (if present)

### B. Track Info Exclusion
- Track counts, individual track titles, performers, pregaps, and index timestamps are intentionally excluded from the diff comparison.

### C. Backup File Resolution
- When a file is saved in `CueFileWriter.Save`, a backup is written as `filePath + ".bak"`.
- If `<filePath>.bak` does not exist, notify the user with a dialog: *"No backup file (.bak) found for this release."*

---

## 3. Architecture & Components

### Component 1: `Core/HeaderDiffService.cs` (Core Logic)
Create a dedicated comparison service in `Core` decoupled from the UI:
- **`HeaderFieldDiff` Model**:
  ```csharp
  public enum DiffKind { Unchanged, Added, Modified, Removed }

  public record HeaderFieldDiff(
      string FieldName,
      string? BackupValue,
      string? CurrentValue,
      DiffKind Kind
  );
  ```
- **`HeaderDiffResult` Model**:
  - `string CueFilePath`
  - `string BackupFilePath`
  - `bool HasBackup`
  - `List<HeaderFieldDiff> Fields`
  - `int TotalChanges => Fields.Count(f => f.Kind != DiffKind.Unchanged)`
- **`HeaderDiffService.Compare(CueData? backupData, CueData? currentData)`**:
  - Compares each of the 11 header fields.
  - Normalizes empty strings and nulls to avoid false positives.
  - Returns `HeaderDiffResult`.

### Component 2: `UI/DiffDialog.cs` (TUI Modal View)
A modal `Dialog` using `Terminal.Gui`:
- **Dimensions**: Centered, flexible width (85% width or 90 cols, height 22 lines).
- **Header / Title**: `Diff: <filename> (X changes)`
- **Layout**:
  - **Side-by-Side Comparison**:
    - Left FrameView: `Backup (.bak)` showing backup values.
    - Right FrameView: `Current (.cue)` showing current values.
    - Fields with differences marked with visual badges (e.g. `[MODIFIED]`, `[ADDED]`, `[REMOVED]`) or side-by-side aligned rows.
  - **Alternative Unified / Table View inside Dialog**:
    - A formatted `TableView` or padded `TextView`:
      ```
      Field     Backup (.bak)          Current (.cue)         Status
      ------------------------------------------------------------------
      Artist    Flotsam and Jetsam     Flotsam & Jetsam       [MODIFIED]
      Album     Doomsday for the Dec.  Doomsday for the Dec.
      Date                             1986                   [ADDED]
      Cat No    WMC5-78                WMC5-78
      Country   Japan                  JP                     [MODIFIED]
      ```
  - **Actions**:
    - `Close` button (`Esc` / `Enter` / `Q` hotkey).

### Component 3: `MainWindow` Integration
- **Status Bar**:
  - Add status item: `new StatusItem(Key.Null, "~D~ Diff", () => ShowDiff())`.
- **Keyboard Handling (`RootKeyEvent`)**:
  - Map `D` / `d` to invoke `ShowDiff()`.
- **`ShowDiff()` Method**:
  1. Retrieve selected file path from `_fileListView`.
  2. Check if backup file `filePath + ".bak"` exists.
  3. If not found: display `MessageBox.Query("No Backup", $"No backup file (.bak) found for:\n{Path.GetFileName(filePath)}", "OK")`.
  4. If found: parse both using `CueFileParser.Parse(...)`, run `HeaderDiffService.Compare(...)`, and display `DiffDialog`.
