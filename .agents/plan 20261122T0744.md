# Implementation Plan - Apply Selected Row Color Scheme to Search Results Pane

## Overview
Apply the same selected row color scheme (`Color.BrightYellow` foreground, `Color.DarkGray` background when focused, `Color.Blue` background when unfocused) to the "Search Results" pane (`_resultsListView`), matching the "Cue Files" pane.

## Proposed Changes

### 1. UI Updates: `UI/MainWindow.cs`
- Create a shared helper `ApplyListRowColorScheme(ListView listView)`:
  - Assigns custom `ColorScheme` with `Focus` and `HotNormal` / `HotFocus` using `Color.BrightYellow`.
  - Attaches `RowRender` handler to render `args.Row == listView.SelectedItem` with `Color.BrightYellow` foreground on the appropriate background (`DarkGray` when focused, `Blue` when unfocused).
- Apply `ApplyListRowColorScheme` to both `_fileListView` and `_resultsListView`.

### 2. Unit Tests: `CueComplete.Tests/MainWindowTests.cs`
- Add unit test `MainWindow_SearchResultsPane_SelectedRowRendersYellow`:
  - Populate `_resultsListView` with items.
  - Verify that `RowRender` sets `Color.BrightYellow` foreground for the selected row when focused and unfocused.
  - Verify that unselected rows are not overridden with yellow.

### 3. Verification & Packaging
- Run `dotnet test` to verify all unit tests pass.
- Run `dotnet build -c Release`.
- Run `dotnet publish -c Release -r win-x64 -p:PublishSingleFile=true --self-contained true`.
- Log progress in `.agents/progress.md`.
- Commit changes using Conventional Commits and push to the feature branch.
