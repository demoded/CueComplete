# Plan: Match Artist Acronyms in Search & String Extensions

## Problem Analysis
When searching for metadata for `TestStubs\1987 - Get It Now [Steps, 73053, Unofficial]\Metal Priest - Get It Now.cue`:
1. Source CUE data:
   - Artist: `Metal Priest`
   - Album: `Get It Now`
   - CatNo: `73053`
2. Fast Search queries Discogs by catalog number (`catno=73053`).
3. Discogs returns 111 releases for `catno=73053`. Release 4877242 is the exact match:
   - `id`: `4877242`
   - `title`: `"MP (22) - Get It Now"`
   - `catno`: `"73053"`
   - `label`: `["Steps Records"]`
   - `master_url`: `"https://api.discogs.com/masters/593145"` (Year 1987)
4. However, `DiscogsProvider.PerformDiscogsSearchAsync` filters candidates by comparing the parsed artist (`"MP"`) with `sourceData.Artist` (`"Metal Priest"`) using `StringExtensions.MatchesArtist`.
5. Because `"MP"` is not a substring of `"Metal Priest"` and `"Metal Priest"` is not a substring of `"MP"`, `MatchesArtist` returns `false`.
6. Result: All 50 page-1 results are discarded (`Filtered Discogs search results by artist 'Metal Priest': count changed from 50 to 0`), returning 0 matches.
7. Subsequent text search for `"Metal Priest Get It Now"` also returns 0 matches because the release on Discogs is indexed under `"MP - Get It Now"`.

## Proposed Solution
1. **Acronym / Initialism Matching in `StringExtensions`**:
   - Add `IsAcronymMatch(string? str1, string? str2)` in [`Core/StringExtensions.cs`](file:///D:/git/CueComplete/Core/StringExtensions.cs) called by `MatchesArtist`.
   - Support bidirectional acronym matching:
     - Acronym candidate: 2 to 6 characters, all letters.
     - Likely acronym check: length 2, dotted format (e.g. `M.P.`, `m.p.`), or all uppercase (e.g. `MP`, `ELO`, `CCR`, `BOC`, `RHCP`, `OMD`, `ELP`, `CSNY`).
     - Words candidate: split into words, extracting first letters.
     - Compare initials with diacritic and case insensitivity (`InvariantCompareInfo.Compare(..., DiacriticAndCaseInsensitiveOptions) == 0`).
     - Exact length check: initials count must equal the acronym length to avoid false positives.
     - Support full word list or list excluding common stopwords (`a, an, the, and, or, of, in, on, at, by, for, with, to, de, der, die, das, la, le, les, du, des, und, et`).
   - Normalize Discogs numerical suffixes (`\s*\(\d+\)$`) in `NormalizeArtist`.
   - Add public helper `GetAcronym(string? artist)` returning the standard acronym of a multi-word artist.

2. **Acronym Query Fallback in Text Search**:
   - In [`Core/MetadataService.cs`](file:///D:/git/CueComplete/Core/MetadataService.cs) and [`Core/Metadata/DiscogsProvider.cs`](file:///D:/git/CueComplete/Core/Metadata/DiscogsProvider.cs):
     - When searching by artist and album yields 0 results, if the artist has an acronym (e.g. `MP` for `Metal Priest`), retry search with `"{acronym} {album}"` (e.g. `MP Get It Now`), which directly finds the release even if no catalog number was provided.

3. **Testing & Verification**:
   - Add comprehensive unit tests in [`CueComplete.Tests/StringComparisonTests.cs`](file:///D:/git/CueComplete/CueComplete.Tests/StringComparisonTests.cs):
     - `MatchesArtist` test cases: `"MP"` <-> `"Metal Priest"`, `"M.P."` <-> `"Metal Priest"`, `"ELO"` <-> `"Electric Light Orchestra"`, `"OMD"` <-> `"Orchestral Manoeuvres in the Dark"`, `"BOC"` <-> `"Blue Öyster Cult"`, `"ЧК"` <-> `"Чёрный Кофе"`.
     - Negative test cases: `"MP"` vs `"Michael Jackson"`, `"MP"` vs `"Madonna"`, `"War"` vs `"We Are Right"`, `"M"` vs `"Metallica"`.
     - `GetAcronym` test cases.
     - DiscogsProvider CatNo search integration test simulating Discogs response for `73053` and verifying `MP (22) - Get It Now` is matched for `Metal Priest`.
   - Run `dotnet test`.
   - Build Release and run `dotnet publish -c Release -r win-x64 -p:PublishSingleFile=true --self-contained true`.
