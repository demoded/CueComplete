# Implementation Plan - Cue Files Color Tweak (Issue #20)

## Overview
Implement GitHub Issue #20: `Cue Files color tweak`.
Change the selected file in the `Cue Files` pane (`_fileListView`) to yellow (`Color.BrightYellow`) so that the currently selected/active CUE file is clearly distinguishable whether the pane has focus or not.

## Proposed Changes

### 1. UI Updates: `UI/MainWindow.cs`
- In `MainWindow` constructor where `_fileListView` is instantiated and configured:
  - Configure `_fileListView.ColorScheme` with a custom scheme based on `Colors.Base`:
    - `Focus`: `(Color.BrightYellow, Color.DarkGray)`
    - `HotNormal`: `(Color.BrightYellow, Color.Blue)`
    - `HotFocus`: `(Color.BrightYellow, Color.DarkGray)`
  - Attach `_fileListView.RowRender` handler:
    - For `args.Row == _fileListView.SelectedItem`:
      - If `_fileListView.HasFocus`: `args.RowAttribute = new Terminal.Gui.Attribute(Color.BrightYellow, Color.DarkGray);`
      - If unfocused: `args.RowAttribute = new Terminal.Gui.Attribute(Color.BrightYellow, Color.Blue);`
    - Leaves non-selected rows to render with default theme styling (`Color.White, Color.Blue`).

### 2. Unit Tests: `CueComplete.Tests/MainWindowTests.cs`
- Add unit test `MainWindow_CueFilesPane_SelectedFileRendersYellow`:
  - Verify that when `_fileListView` renders the selected row:
    - If `_fileListView` is focused, `RowAttribute.Foreground` is `Color.BrightYellow`.
    - If `_fileListView` is unfocused, `RowAttribute.Foreground` is `Color.BrightYellow`.
  - Verify that unselected rows do not have their row attribute overridden with yellow.
- Restore the `MainWindow_TabNavigation_FlowsFromCueFilesToSearchResultsToFoundCueData` test that was temporarily replaced during diagnostic tests.

### 3. Verification & Packaging
- Run `dotnet test` to verify all unit tests pass.
- Run `dotnet build -c Release`.
- Run `dotnet publish -c Release -r win-x64 -p:PublishSingleFile=true --self-contained true`.
- Log progress in `.agents/progress.md`.
- Commit changes using Conventional Commits and push to the feature branch.
- Open GitHub Pull Request for Issue #20.
