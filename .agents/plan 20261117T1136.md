# Plan: Upgrade CueComplete to .NET 11

## Overview
Upgrade the CueComplete solution from .NET 10 to the newly released .NET 11 (`net11.0`).

## Motivation & Benefits
- Modernize the runtime and target framework to .NET 11.
- Take advantage of .NET 11 runtime and JIT performance enhancements.
- Eliminate obsolete/redundant package references (e.g. `System.Text.Encoding.CodePages` warning NU1510).
- Update CI/CD workflow to ensure automated GitHub release builds run on .NET 11 SDK.

## Scope of Changes
1. **CueComplete.csproj**:
   - Change `<TargetFramework>` from `net10.0` to `net11.0`.
   - Remove redundant `System.Text.Encoding.CodePages` package reference to resolve warning NU1510.
2. **CueComplete.Tests/CueComplete.Tests.csproj**:
   - Change `<TargetFramework>` from `net10.0` to `net11.0`.
3. **.github/workflows/release.yml**:
   - Update `setup-dotnet` step with `dotnet-version: '11.0.x'`.
4. **README.md**:
   - Update documentation references from .NET 10 to .NET 11.
5. **Testing & Verification**:
   - Run `dotnet restore` to verify package compatibility.
   - Run `dotnet test` to confirm all 102 unit tests pass on `net11.0`.
   - Run `dotnet build -c Release` and package via `dotnet publish -c Release -r win-x64 -p:PublishSingleFile=true --self-contained true`.
6. **Progress Tracking & Git**:
   - Update `.agents/progress.md` with timestamped log entry.
   - Commit changes using Conventional Commits (`feat: upgrade project to .NET 11`).
