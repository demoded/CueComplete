# Plan: Double the Width of the Cue Files Pane

## Overview
Increase the width of the `Cue Files [nnn/NNN]` pane in `MainWindow` by 2x from its current value (from 20% to 40% of the screen width).

## Motivation
With longer folder paths, album names, or catalog metadata displayed in the left files list, a 20% column width can truncate folder/file names. Doubling the width to 40% provides more room for viewing items comfortably while leaving 60% for the search results pane.

## Proposed Changes
1. **UI/MainWindow.cs**:
   - Change `_cueFilesPane.Width = Dim.Percent(20)` to `_cueFilesPane.Width = Dim.Percent(40)`.
   - `_searchResultsPane` is already positioned at `X = Pos.Right(_cueFilesPane)` with `Width = Dim.Fill()`, so it will automatically adjust to occupy the remaining 60% of the horizontal space.
2. **CueComplete.Tests/MainWindowTests.cs**:
   - Add test assertion verifying `window.CueFilesPane.Width` is equal to `Dim.Percent(40)`.
3. **Verification**:
   - Run `dotnet test` to ensure all unit tests pass.
   - Run `dotnet build -c Release` and `dotnet publish -c Release -r win-x64 -p:PublishSingleFile=true --self-contained true` per instructions.
4. **Progress Logging**:
   - Document changes in `.agents/progress.md`.
