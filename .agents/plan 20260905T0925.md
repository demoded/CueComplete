# Plan: Add File Counter to CUE Files Pane

## Problem Summary
The user requested adding a counter to the `CUE Files` pane in the UI, displaying the current file number and the total number of files in the format `[current\total]`.

## Implementation Strategy

1. **Promote `leftPane` to a Class Field**:
   - In `UI/MainWindow.cs`, store the `FrameView` instance as `private FrameView _leftPane;` so its title can be updated dynamically.

2. **Add `UpdateLeftPaneTitle()` Helper**:
   - Compute `current`:
     - If `_cueFiles.Count == 0`, `current = 0`.
     - Otherwise, if `_fileListView.SelectedItem >= 0`, `current = Math.Min(_fileListView.SelectedItem + 1, _cueFiles.Count)`.
     - Otherwise, fallback to `1`.
   - Update `_leftPane.Title = $"CUE Files [{current}\\{_cueFiles.Count}]";`
   - Trigger `_leftPane.SetNeedsDisplay()`.

3. **Hook Selection Events & State Changes**:
   - Initialize title during `MainWindow` constructor.
   - Update in `_fileListView.SelectedItemChanged`.
   - Update in `_fileListView.Enter`.
   - Update in `ResultsListView_OpenSelectedItem` when advancing to `nextIndex`.

4. **Verification**:
   - Run `dotnet test` to ensure existing tests pass.
   - Run `dotnet build` and `dotnet publish -c Release -r win-x64 -p:PublishSingleFile=true --self-contained true` as required by project rules.
   - Update `.agents/progress.md`.
