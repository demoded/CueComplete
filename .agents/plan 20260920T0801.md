# Plan: Implement Diacritic- and Case-Insensitive String Comparison with CompareOptions

## Problem Summary
When searching Discogs or MusicBrainz, candidate releases are filtered by comparing the candidate artist name against the user's search artist name.
Currently, this comparison uses `.ToLowerInvariant().Contains(...)`. In .NET, standard ordinal/invariant string methods treat characters with diacritics, accents, and combining marks—such as Cyrillic `ё` vs `е` (`Чёрный Кофе` vs `Черный Кофе`), or Latin accented characters (`Motörhead` vs `Motorhead`, `Beyoncé` vs `Beyonce`)—as distinct characters. This causes valid matching releases (such as `MR 23143 CD`) to be erroneously filtered out.

## Solution Strategy
1. **Create `Core/StringExtensions.cs`**:
   - Provide helper methods:
     - `ContainsIgnoreCaseAndDiacritics(this string? source, string? target)`: Performs substring check using `CultureInfo.InvariantCulture.CompareInfo.IndexOf(source, target, CompareOptions.IgnoreCase | CompareOptions.IgnoreNonSpace) >= 0`.
     - `MatchesArtist(string? candidate, string? target)`: Performs bidirectional check (`ContainsIgnoreCaseAndDiacritics(candidate, target) || ContainsIgnoreCaseAndDiacritics(target, candidate)`), ignoring leading/trailing whitespace.
2. **Update `DiscogsProvider.cs`**:
   - In `SearchAsync` and `PerformDiscogsSearchAsync`, replace standard `.ToLowerInvariant().Contains(...)` with `StringExtensions.MatchesArtist(d.Artist, sourceData.Artist)`.
3. **Update `MusicBrainzProvider.cs`**:
   - In DiscID post-filter, FreeDB post-filter, and text search post-filter, replace `.ToLower().Contains(...)` with `StringExtensions.MatchesArtist(...)`.
4. **Add Unit Tests in `CueComplete.Tests`**:
   - Add tests verifying:
     - Cyrillic `ё` vs `е` (`Черный Кофе` matches `Чёрный Кофе`).
     - Diacritic variations (`Motörhead` matches `Motorhead`, `Beyoncé` matches `Beyonce`).
     - Substring variations (`Joan Jett` matches `Joan Jett & the Blackhearts`).
     - Non-matches (`Daevid Allen` does not match `Joan Jett`).
     - Discogs artist filtering integration with `MR 23143 CD` metadata.
5. **Build and Publish**:
   - Run `dotnet test`.
   - Run publish command: `dotnet publish -c Release -r win-x64 -p:PublishSingleFile=true --self-contained true`.
   - Update `.agents/progress.md`.
